## 📁 Projects

### ▫️ Lingario — English vocabulary app

Learning new words is easy, but remembering them is hard. Lingario, built for a local English school and used by 20+ learners, tracks each word with a custom spaced repetition algorithm and brings it back right before you forget it. AI writes an example sentence for every word, with 3 retries and a fallback model if it fails.

- Saves teachers ~2 hours a week: a built-in 3,000-word Oxford dictionary replaced hand-made word lists.
- The dictionary opens in under 1s instead of 3s thanks to caching, and renders 9x faster with list virtualization.

`React` `TypeScript` `Redux Toolkit` `React Router` `Tailwind CSS` `Firebase` `Gemini API`

**[Open the app →](https://lingario.app)**

### ▫️ Calm Pairs — memory card game

A memory-matching game in plain TypeScript, with no frameworks, working directly with the DOM. Four difficulty levels, a timer, sounds, and results saved in localStorage. Scores 90+ in Lighthouse Performance.

`TypeScript` `Sass` `Vite`
